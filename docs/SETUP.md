# 搭建与运行说明（待实机验证）

本文件提供分段实施路线，不是已验证的逐动作安装教程。具体动作名称、可取得的健康样本属性和邮件附件输入方式，以自己的 iOS 版本为准。不要直接把 ZIP 导入快捷指令。

## 1. 确认数据源

打开 Mi Fitness，完成同步。在 Apple 健康分别检查睡眠、心率和步数的数据源及最近记录。记下设备上实际显示的来源名称。缺少某类数据时先处理同步和写入权限。

## 2. 从一个健康查询开始

在「快捷指令」中新建 `lizi Health Daily`，添加「查找健康样本」并先选择睡眠。先手动运行并预览样本，确认能取得开始时间、结束时间、类别值；单独核对来源属性是否可用。

确认后再加入本地日历日期边界，依照 [数据规范](DESIGN.md) 设置窗口。若界面只支持按开始时间筛选，为避免漏掉跨边界样本，可扩大查询开始范围，再对每条样本按区间重叠条件筛选。

## 3. 加入心率、步数和对象数组

复制查询结构，分别读取心率和步数。对每类样本执行循环，逐条建立字典，并汇总为对象数组。来源筛选必须依据实际观察到的名称；属性不可用时，在警告中说明。

先预览三个数组，再组合顶层字典。空查询输出空数组，并记录查询状态。按 [示例](../examples/health_example.json) 组织字段，核对数值单位和带时区日期。

## 4. 保存文件

将字典序列化为实际 JSON 文本，设定文件名为 `health_YYYY-MM-DD.json`。保存到 `iCloud Drive/Shortcuts/lizi-health/`，先完成目录和写入授权，再关闭每次询问保存位置。

在「文件」App 打开输出，确认内容确实可解析，不能仅凭扩展名认定成功。重复运行时覆盖相同日期文件；邮件是否重复发送应另行设计，覆盖文件不代表阻止重复发信。

## 5. 加入邮件发送

先在 Apple Mail 中登录自己的邮箱。添加「发送电子邮件」动作，在设备上选择收件人和发件账户，主题设置为 `lizi Health Daily - 日期`。

将已保存的 JSON 文件作为邮件动作的文件输入或附件，具体位置以动作界面为准。保持「显示编写表单」开启，检查邮件实际带有 `.json` 附件，而不是只包含文件路径或文件名。手动确认第一次发送，检查收到的文件可以解析。

本仓库不包含收件地址，也没有发送任何邮件。通过首轮检查后，才能在自己的设备上关闭编写表单，测试自动发送。

## 6. 每日自动化

在快捷指令的「自动化」中创建每天特定时间触发，加入「运行快捷指令」并选择 `lizi Health Daily`。可从 09:00 开始；选择设备界面提供的「立即运行」或不逐次询问设置。

个人自动化需在 iPhone 上单独创建。即使未来发布可导入快捷指令，也不应宣称导入会自动安装每天的定时触发。

先完成 [验收清单](VALIDATION.md)。分别测试解锁、锁屏、重启后及数据未同步时的行为。09:00 前未完成 Mi Fitness 同步，就不能期待日报自动拥有最新数据。
